Loading

Parent apps can block typing while backend verification is running.

otpRef.loading.set(true);
verify(code).finally(() => otpRef.loading.set(false));

Error state

Angular form errors show clear messages after the control is touched.

otp.markAsTouched();
otp.setErrors({ invalidOtp: true });
otp.setErrors({ otpExpired: true });

Web OTP

Supported Android Chrome browsers can offer SMS OTP autofill.

config: OtpAngularType = {
  length: 6,
  numbersOnly: true,
  autoSubmit: true,
  autoSubmitValidOnly: true,
  webOtp: true
};
